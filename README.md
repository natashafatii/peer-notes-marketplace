# 📚 Notes Marketplace

[![Flutter](https://img.shields.io/badge/Flutter-3.16+-blue.svg)](https://flutter.dev)
[![Supabase](https://img.shields.io/badge/Supabase-2.10+-green.svg)](https://supabase.com)
[![License](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

A complete **Flutter-based Notes Marketplace application** where students can upload, share, browse, and download academic notes. Users can earn credits by uploading notes and spend credits to unlock premium content.

---

# ✨ Features

## 🔐 Authentication
- Email & Password Sign Up/Login
- Secure Session Management
- Remember Me Functionality

---

## 📱 Core Features
- 📤 Upload Notes (PDF, DOC, DOCX, PPT, PPTX, Images)
- 📥 Download Free & Premium Notes
- 🔎 Search Notes by Title
- 🗂️ Filter by Categories
- ⭐ Ratings & Reviews System
- 🔖 Bookmark / Save Notes
- 📊 Sort Notes:
  - Most Recent
  - Highest Rated
  - Most Popular
  - Price

---

## 💰 Credit System
- 🎁 10 Free Credits on Signup
- ➕ Earn 5 Credits per Upload
- 💎 Premium Notes Cost 15 Credits
- 🔄 Real-Time Credit Balance Updates

---

## 👤 Profile Features
- Upload Profile Picture
- Edit User Information
- View Uploaded Notes
- Edit Uploaded Notes
- View Downloaded Notes
- Saved Notes Section
- Credit Balance & Activity

---

## 🎨 UI/UX Features
- 🌙 Light & Dark Mode
- ✨ Smooth Animations

# ⚙️ Installation

## 1️⃣ Clone Repository

```bash
git clone https://github.com/natashafatiii/peer-notes-marketplace.git
```

---

## 2️⃣ Open Project

```bash
cd peer-notes-marketplace
```

---

## 3️⃣ Install Dependencies

```bash
flutter pub get
```

---

## 4️⃣ Setup Supabase

- Create a Supabase Project
- Create Database Tables
- Create Storage Buckets:
  - `notes`
  - `avatars`
- Configure Authentication
- Enable Row Level Security (RLS)



---

## 6️⃣ Run Application

```bash
flutter run
```

---

# 🎯 Key Features Explained

## 💳 Credit System

- New users receive 10 free credits
- Uploading notes gives +5 credits
- Unlocking premium notes costs 15 credits
- Real-time balance updates

---

## 📅 Daily Upload Limit

- Maximum 5 uploads per day
- Counter resets every 24 hours

---

## 💎 Premium Notes

- Premium notes require credits
- Locked content until purchased
- Mock payment support included

---

## 📁 Supported File Types

- 📄 PDF
- 📝 DOC / DOCX
- 📊 PPT / PPTX
- 🖼️ JPG / PNG / JPEG
